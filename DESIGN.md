# Складская практика — информационный журнал

Обложка главного материала, светлое поле, тёмно-зелёный текст, натуральные складские сюжеты. Главная разделена по задачам: начать чтение, подобрать рубрику, выполнить расчёт, пройти подборку. Статьи имеют иллюстрации, локальное оглавление, таблицы, шаги и связанные материалы.

Авторство: редакция. Подтверждённые сведения о RFL находятся на rfl.ru; журнал не принимает заявки и не продаёт услуги. В статьях ссылки на RFL размещены только рядом с темой, которую продолжает целевой URL.

Иллюстрации сгенерированы встроенным ImageGen. Сцены не показывают реальные объекты RFL и клиентов. Оригиналы сохранены локально в design/media-originals, в Git включены только версии WebP в public/photos. Сюжеты: общий план складского проезда, паллеты на стеллажах, упаковочный стол, погрузочный док, рабочий стол логиста. Сюжеты подготовлены в виде редакционной фотографии без брендов, текста и узнаваемых лиц.

Основной цвет #17362f, фон #f4f1e8, текст #1b2924, акцент #ddf1a8. Фото-зоны используют responsive srcset и crop контейнера без обрезки текста. Обложки статей и карточки имеют проверенные размеры, мобильная сетка складывается.
