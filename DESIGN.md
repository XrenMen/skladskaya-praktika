# Складская практика

Информационный журнал о работе склада. В действующей версии главная и статьи оформлены по мотивам [MUBI Notebook](https://ui.gradientdeck.com/styles/mubi-notebook). На главной собраны широкая фотография ведущего материала, лента статей с поиском по заголовкам и описаниям, фильтры рубрик и ссылки к рабочим инструментам. В архиве доступны все статьи, отдельный поиск по текстам работает через Pagefind.

Белый фон, чёрный текст и тонкие серые линии задают основу. Тёмный бордовый (#78283F) используется для ссылок, активных состояний и фокуса. Интерфейс набран локальным Source Sans 3 с кириллицей. Лицензия находится в `public/licenses/Source-Sans-3.txt`. Цвет в ленте дают реальные фотографии из редакционного реестра. Снимки не изображают объекты RFL.

Заголовок, фотография и текст материала выровнены по одной читательской колонке. Связанные статьи и подходящий инструмент стоят рядом на широком экране, под текстом на узком. Оглавление помогает перейти к нужному разделу. На всех HTML-страницах стоит `noindex`.

## Правила, закреплённые после правок

- На наведении текст ссылки и заголовок карточки меняют цвет. Подчёркивание не появляется. Так строка остаётся визуально спокойной. Для ссылок внутри абзаца допустимо постоянное подчёркивание, чтобы переход был заметен сразу. При `Tab` фокус обведён.
- Для статей подбираем реальные фотографии с разрешением на использование. Данные об авторах, источниках и лицензии храним в редакционном реестре. Снимок показывает операцию или предмет из статьи, чтобы по нему было понятно, о чём материал.
- У раздела есть читаемая практическая задача: открыть конкретный материал, выбрать рубрику или сделать расчёт. Связанные статьи подбираем по тому, что читатель будет делать дальше. Это помогает ориентироваться в журнале и сокращает повторение одинаковых блоков.
- Для основной типографики используем локальный Source Sans 3 с кириллицей. Иерархию строим размером, весом и интервалами. Для коротких действий используем понятные названия, которые можно прочитать отдельно от блока.
