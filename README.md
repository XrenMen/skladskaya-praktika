# Складская практика

Практический сайт для логистов и закупщиков, отдельный от [RFL](https://rfl.ru/). Три рубрики, восемь редакционных статей, поиск Pagefind, RSS и калькулятор паллето-дней.

## Исходники

Ветка `codex/skladskaya-praktika`: Astro, стили, редакционные модули, SVG и проверка сборки. Установите Node.js 22.12+ и выполните:

```
npm ci
npm run check
npm run build
npm run preview
```

Pagefind формирует поисковый индекс во время сборки. Для изменения статьи обновите соответствующий модуль в `content/`. Читайте `brief.md` и `DESIGN.md`.

## Выпуск

Ветка `main` содержит только собранный сайт и этот README. Источник Pages — `main`, `/(root)`. Перед заменой файлов запишите текущий SHA; для отката сделайте revert коммита выпуска. Не загружайте исходники, служебные каталоги и зависимости в корень Pages.

В `src/layouts/Site.astro` на всех HTML предусмотрен `noindex`, включая поиск и страницу 404. Не добавляйте блокировку обхода каталога в robots.txt: робот должен видеть директиву. Это не ограничение доступа по прямой ссылке.
