# Складская практика

Статический справочник по складской логистике. Главная содержит три рабочих памятки и калькулятор паллето-дней. Расчёт выполняется в браузере: поля не отправляются и не сохраняются.

## Просмотр и выпуск

Откройте index.html для локального просмотра. На GitHub Pages источник — ветка main, папка /(root). 404.html ссылается на корень проектного сайта /skladskaya-praktika/.

В head каждой HTML-страницы требуется meta robots с noindex. Не закрывайте эти страницы через robots.txt: робот должен прочитать метатег. Noindex не ограничивает доступ по ссылке.
