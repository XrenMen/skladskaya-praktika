# Brief · Складская практика

- Основной проект: https://rfl.ru/; отдельный справочник для закупщиков, руководителей склада и логистов.
- Формат: информационный B2B-журнал на русском языке. 3 рубрики, 8 статей, полнотекстовый поиск и калькулятор. Тарифы, контакты и предложения бизнеса остаются на сайте RFL.
- Технический адрес: https://xrenmen.github.io/skladskaya-praktika/. Это существующий GitHub Pages-стенд проекта без отдельного домена. Архивный домен не предоставлен; паспорт заимствованной истории и перенос чужих URL здесь неприменимы.
- Сравнение было/стало: вместо одной страницы и кратких памяток — фотообложка, редакционные подборки, блог, отдельные статьи, рубрики и поиск; прежний корень сайта сохранён. Связь с RFL раскрыта на странице проекта.
- Примеры вымышленные и обозначены как условные; авторство — редакция, без вымышленных персоналий.
- Все HTML-страницы получают noindex из общего шаблона. Индексируемая карта не подаётся; RSS используется как лента, без создания HTML-дублей.
- Связь с RFL: ссылки только по смыслу. Сайт RFL и его настройки не изменяются.
- Приёмка: сборка, типы, внутренние ссылки, noindex, поиск, калькулятор, рабочие HTTP 200 и 404 на GitHub Pages.
